# Fugleramme clients

Community-made programs that show your [Fugleramme](https://github.com/arnegiacomo/fugleramme) on other devices, like battery-powered e-inks or other external displays.

Want an all-in-one build or want no custom hardware? Use a [Pi with an Inky Impression](https://arnegiacomo.dev/fugleramme/) or show it through [HDMI or in a browser](https://arnegiacomo.dev/fugleramme/screens). Want to tinker, learn and share your setups? Then you've come to the right place!

Got Fugleramme running on a device that isn't listed? Add your program and share it with the community - see [CONTRIBUTING.md](CONTRIBUTING.md).

Every program uses the endpoints in [Fugleramme's docs](https://arnegiacomo.dev/fugleramme/screens/#on-an-external-e-ink-panel). If somethings missing or wrong, open an issue [there](https://github.com/arnegiacomo/fugleramme/issues).
